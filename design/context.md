# Módulo: Design

Fonte da verdade de **game design**: o que o survivor é, faz e sente. ← [CONTEXT.md](../CONTEXT.md)
Nenhum código aqui. Os módulos de código implementam o que está decidido aqui.

## Documentos (a criar conforme avançarmos)
| Arquivo | Conteúdo |
|---|---|
| `concept.md` | Identidade: fantasia do personagem, silhueta, paleta, tema, papel (melee/ranged/etc.) |
| `kit.md` | Passiva + Primária/Secundária/Utilitária/Especial (e alternativas): comportamento, números iniciais, intenção |
| `balance.md` | Histórico de ajustes de balanceamento e o motivo de cada um |
| `lore.md` | Logbook, falas, descrições, textos de seleção (vira tokens em Resources/Language) |

## Regras
- **100% original.** Nada de copiar personagem, nome, arte ou kit existente. Inspirações de *gênero* são ok
  e ficam registradas como inspiração, não como cópia.
- Cada skill no `kit.md` deve ter uma **intenção** (por que existe, que decisão ela dá ao jogador).
- Mudou um número no código? Registre em `balance.md`.
- Coerência com o RoR2: skills devem escalar com dano/velocidade de ataque e interagir bem com itens (proc coefficient).
